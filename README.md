### Bank Mode Text
- Replaces the Insert/Swap mode icon with text ("Insert" or "Swap")
- Replaces the Note mode icon with text ("Note")
- Text turns white when hovering over the button
- Configurable label font (Plain 11, Plain 12 or Bold 12) and text color
- Displays Swap and Insert stacked on the button, with the active mode highlighted (can be turned off to show a single label instead)
